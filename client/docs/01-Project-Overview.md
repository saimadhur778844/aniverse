# Aniverse Marketplace

Version: 1.0.0

---

# Overview

Aniverse Marketplace is a modern full-stack anime collectibles eCommerce platform built using the MERN ecosystem.

The platform allows customers to browse and purchase anime merchandise such as figures, keychains, posters, manga, die-cast models, apparel, and collectibles through a fast, secure, and responsive web application.

The project includes a complete customer storefront, a powerful administrator dashboard, coupon management, payment integration, order management, inventory management, customer management, review system, invoice generation, and analytics.

---

# Goals

The primary objectives of Aniverse are:

- Deliver a premium shopping experience
- Sell authentic anime merchandise
- Support secure online payments
- Manage inventory efficiently
- Provide detailed analytics
- Build a scalable architecture
- Maintain clean and reusable code
