# 🌸 Aniverse Marketplace

A modern full-stack anime collectibles eCommerce platform built with **Next.js**, **Node.js**, **Express**, **MongoDB**, and **Cashfree Payments**.

Aniverse provides a complete online shopping experience for anime enthusiasts, featuring secure authentication, online payments, order management, customer reviews, coupons, inventory management, and a powerful admin dashboard.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/<your-username>/aniverse.git

cd aniverse
```

---

## Backend

```bash
cd server

npm install

npm run dev
```

---

## Frontend

```bash
cd client

npm install

npm run dev
```
